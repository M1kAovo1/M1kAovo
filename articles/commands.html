Git / GitHub

日常网站更新

git status --short（查看修改）
git add -A（暂存所有未忽略的改动）
git diff --cached --stat（检查提交文件）
git commit -m "Update website"（记录一次本地版本）
git push origin main（上传到 GitHub）

查看代码变化

git diff
git diff -- app.js
git log -1 --oneline
